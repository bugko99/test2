# BUGKOShop (ระบบรับเรื่องร้องเรียนศูนย์ดำรงธรรมจังหวัดศรีสะเกษ - DCMS)

## Project Overview
ระบบรับเรื่องร้องเรียนศูนย์ดำรงธรรม (DCMS) เป็นระบบสำหรับจัดการเรื่องร้องเรียนจากประชาชน เชื่อมต่อระหว่างศูนย์ดำรงธรรมและหน่วยงานที่เกี่ยวข้อง

## Development Status
- **Current Phase:** Phase 1: Project Setup (Completed)
- **Next Phase:** Phase 2: Database Schema and Seed Data

## Tech Stack
- Frontend: React + Vite + MUI
- Backend: Node.js + Express
- Database: MySQL 8
- Dev Infrastructure: Docker Compose

## Quick Start (Dev)
1. Start MySQL Database: `docker-compose up -d`
2. Start Backend: `cd backend && npm run dev` (Runs on port 5001)
3. Start Frontend: `cd frontend && npm run dev` (Runs on port 5173)
