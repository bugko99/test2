# System Overview: ระบบรับเรื่องร้องเรียนศูนย์ดำรงธรรมจังหวัดศรีสะเกษ (DCMS)
(Project Name: BUGKOShop)

## 1. บทนำ (Introduction)
ระบบรับเรื่องร้องเรียนศูนย์ดำรงธรรมจังหวัดศรีสะเกษ (Damrongdhama Center Complaint Management System - DCMS) ภายใต้ชื่อโปรเจกต์อ้างอิง BUGKOShop เป็นแพลตฟอร์มที่ถูกออกแบบและพัฒนาขึ้นเพื่อยกระดับการให้บริการประชาชนของศูนย์ดำรงธรรมจังหวัด โดยปรับเปลี่ยนรูปแบบการจัดการข้อร้องเรียนให้เป็นระบบดิจิทัลแบบรวมศูนย์ (Centralized System) 

## 2. วัตถุประสงค์ของระบบ (System Objectives)
- เพื่อเป็นระบบหลักสำหรับบันทึกและจัดการข้อร้องเรียนที่เข้ามายังศูนย์ดำรงธรรมอย่างเป็นหมวดหมู่
- เพื่อลดระยะเวลาและขั้นตอนซ้ำซ้อนในการกระจายงานและส่งต่อเรื่องไปยังหน่วยงานที่รับผิดชอบ
- เพื่อให้สามารถติดตามความคืบหน้า (Tracking) และกำหนดกรอบระยะเวลาดำเนินงานได้อย่างมีประสิทธิภาพ
- เพื่อนำเสนอข้อมูลเชิงสถิติ (Dashboard) ให้ผู้บริหารสามารถนำไปวิเคราะห์ สั่งการ และตัดสินใจได้แบบ Real-time

## 3. ขอบเขตการทำงานหลัก (Core Capabilities)
ระบบได้รับการออกแบบเพื่อรองรับกระบวนการทำงานตั้งแต่ต้นน้ำจนถึงปลายน้ำ (End-to-End) โดยมีคุณสมบัติดังนี้:
1. **การรับเรื่องร้องเรียน (Complaint Submission):** รองรับการบันทึกข้อมูลรายละเอียดข้อร้องเรียน ข้อมูลผู้ร้องเรียน และการแนบไฟล์หลักฐานประกอบ
2. **การส่งต่อหน่วยงาน (Agency Forwarding / Assignment):** เจ้าหน้าที่สามารถจำแนกเรื่องร้องเรียนและส่งต่อ (Assign) ให้กับหน่วยงานที่รับผิดชอบโดยตรง
3. **การติดตามสถานะ (Status Tracking):** รองรับการปรับปรุงสถานะการดำเนินงานในแต่ละขั้นตอน (เช่น รอดำเนินการ, กำลังดำเนินการ, แก้ไขแล้ว, ยุติเรื่อง) 
4. **การบริหารระยะเวลา (SLA & Deadline Management):** กำหนดและติดตามระยะเวลาการดำเนินการให้เป็นไปตามมาตรฐานการปฏิบัติราชการ
5. **การแจ้งเตือน (Notifications):** มีระบบแจ้งเตือนภายใน (In-app notification) เมื่อมีเรื่องร้องเรียนเข้าใหม่ เรื่องใกล้ครบกำหนด หรือสถานะมีการเปลี่ยนแปลง
6. **หน้าปัดแสดงผลและรายงาน (Dashboard & Reporting):** รวบรวมสถิติ จำนวนเรื่องร้องเรียนแยกตามหน่วยงาน แยกตามสถานะ เพื่อแสดงผลบน Dashboard

## 4. กลุ่มผู้ใช้งานระบบ (Target Users)
ระบบจะแบ่งการเข้าถึงและการมองเห็นข้อมูลตามบทบาท (Roles) โดยเบื้องต้นมีกลุ่มผู้ใช้งานหลัก ดังนี้:
1. **เจ้าหน้าที่ศูนย์ดำรงธรรม (DCMS Staff / Admin):** ผู้ใช้หลักที่มีอำนาจครอบคลุมในการรับเรื่อง คัดกรอง ส่งต่อ ตรวจสอบ และบริหารจัดการข้อมูลในระบบ
2. **เจ้าหน้าที่หน่วยงานที่รับผิดชอบ (Agency Officer):** ผู้รับมอบหมายเรื่องร้องเรียน มีสิทธิ์ในการอัปเดตสถานะ รายงานผล และแนบหลักฐานการแก้ไขปัญหา (มองเห็นเฉพาะเรื่องของหน่วยงานตนเอง)
3. **ผู้บริหาร (Executive):** ผู้ใช้ระดับสูงที่ต้องการเข้าถึงข้อมูลภาพรวม สถิติเชิงลึกผ่าน Dashboard โดยไม่จำเป็นต้องเข้าไปยุ่งเกี่ยวกับกระบวนการทำงานระดับปฏิบัติการ

## 5. สถาปัตยกรรมระดับสูง (High-Level Architecture)
โปรเจกต์ BUGKOShop (DCMS) จะถูกพัฒนาด้วยสถาปัตยกรรม Modern Web Application:
- **Frontend (React 18 + Vite 5 + MUI 5):** ทำหน้าที่เป็น User Interface ที่ใช้งานง่าย เป็นระบบ Single Page Application (SPA) ที่ทำงานได้รวดเร็ว
- **Backend (Node.js 20 LTS + Express 4):** ทำหน้าที่เป็น RESTful API จัดการ Business Logic ทั้งหมด ตรวจสอบสิทธิ์ และเชื่อมต่อฐานข้อมูล
- **Database (MySQL 8):** ระบบจัดการฐานข้อมูลเชิงสัมพันธ์ที่มีเสถียรภาพสูง
- **Deployment Strategy:** เพื่อความคล่องตัว จะใช้ `docker-compose` สำหรับการจำลอง Environment ในตอนพัฒนา และ Deploy รูปแบบ Single-container ไปยัง Railway สำหรับระดับ Production
